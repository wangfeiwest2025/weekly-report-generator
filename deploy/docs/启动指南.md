# 启动指南

## 🚀 Windows启动

### 方式一：双击启动（推荐）

1. 双击运行 `web_app/start.bat`
2. 自动检查并安装依赖（首次运行可能需要几分钟）
3. 浏览器自动打开 `http://localhost:8501`
4. 上传文件 → 生成周报 → 下载 docx

### 方式二：命令行启动

```bash
cd web_app
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 🐧 Linux启动

### 方式一：Docker Compose（推荐）

```bash
cd web_app
mkdir -p data
docker-compose up -d
```

### 方式二：直接运行

```bash
cd web_app
chmod +x deploy.sh
./deploy.sh
nohup ./start.sh > logs/app.log 2>&1 &
```

### 方式三：Systemd

```bash
cd web_app
python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
sudo cp weekly-report.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now weekly-report
```

## 🖥️ 使用步骤

1. 打开 `http://localhost:8501`（Linux 服务器为 `http://服务器IP:8501`）
2. 上传"检查原始数据导出"文件
3. 上传"处罚原始数据导出"文件
4. 确认时间范围（上传后自动填充）
5. 点击"🚀 生成周报"
6. 预览正文，点击"📥 下载 docx 文件"

## ❓ 常见问题

| 问题 | 解决 |
|------|------|
| 端口被占用 | `streamlit run streamlit_app.py --server.port 8502` |
| 依赖缺失 | `pip install -r requirements.txt` |
| 防火墙拦截 | 放行 8501 端口（`sudo ufw allow 8501/tcp`） |
| 上传文件失败 | 确认文件为平台导出的 .xls（HTML格式） |
