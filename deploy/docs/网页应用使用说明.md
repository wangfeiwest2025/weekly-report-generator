# 网页应用使用说明

## 📱 网页应用功能

"执法处周报材料生成器"网页版（Streamlit），提供图形化界面，方便上传数据、设置时间、生成周报 docx。

## 🚀 快速启动

### 方法一：双击启动（推荐）

1. 双击运行 `web_app/start.bat`（Windows）
2. 等待自动安装依赖并启动
3. 浏览器自动打开网页应用

### 方法二：命令行启动

```bash
cd web_app
pip install -r requirements.txt
streamlit run streamlit_app.py
```

### 方法三：Linux服务器

```bash
cd web_app
chmod +x deploy.sh && ./deploy.sh
nohup ./start.sh > logs/app.log 2>&1 &
# 访问 http://服务器IP:8501
```

## 📖 界面说明

### 1. 侧边栏
- **时间范围**：本周开始/结束日期（上传文件后自动填充）
- **上周处罚件数**：可留空（自动计算或使用历史记录）
- **使用说明**：操作步骤速览

### 2. 主界面

#### 数据上传区域
- **检查原始数据导出**：上传检查数据.xls（HTML格式，如 检查数据0803.xls）
- **处罚原始数据导出**：上传处罚数据.xls（HTML格式，如 处罚数据0803.xls）

#### 报告生成区域
- **🚀 生成周报按钮**：点击生成
- **正文预览**：显示两段正文，可核对数值
- **📥 下载按钮**：下载生成的 docx 文件
- **运行日志**：可展开查看详细处理过程

## 🎯 使用步骤

### 步骤1：启动应用
双击 `start.bat` 或命令行启动，浏览器访问 `http://localhost:8501`

### 步骤2：上传文件
1. 点击"检查原始数据导出"上传区域，选择 `检查数据0803.xls`
2. 点击"处罚原始数据导出"上传区域，选择 `处罚数据0803.xls`

### 步骤3：设置时间范围
- 上传文件后自动填充本周区间（如 7月27日-8月2日）
- 也可在侧边栏手动调整

### 步骤4：生成报告
1. 点击 **"🚀 生成周报"** 按钮
2. 等待处理完成（约10-30秒，首次读取大文件较慢）
3. 查看两段正文预览

### 步骤5：下载报告
1. 点击 **"📥 下载 docx 文件"** 按钮
2. 选择保存位置
3. 用 Word 打开核对格式

## 📊 生成内容

生成的 docx 包含（格式与样例一致）：
- 标题：执法处建筑市场检查周报材料
- 正文一：本周全市住建系统建筑市场执法情况
  - 检查量（环比/同比）
  - 发现问题数及发现率（环比/同比）
  - 市级专项检查情况
  - 前八区检查分析（检查较多区、未开展检查区、拟立案区）
- 正文二：本周全市住建系统工程建设领域处罚情况
  - 处罚件数（环比/同比）
  - 前八区每百工程处罚量排名

## ⚙️ 高级配置

### 修改端口
```bash
streamlit run streamlit_app.py --server.port 8080
```

### 允许外部访问（Linux服务器）
```bash
streamlit run streamlit_app.py --server.address 0.0.0.0
```

### 配置文件
创建 `.streamlit/config.toml`：

```toml
[server]
port = 8501
address = "localhost"
enableCORS = false

[theme]
primaryColor = "#1f77b4"
backgroundColor = "#ffffff"
secondaryBackgroundColor = "#f0f2f6"
textColor = "#262730"
font = "sans serif"
```

## 📝 常见问题

### Q1: 上传文件时提示错误
- 检查文件格式是否正确（.xls/.xlsx）
- 检查文件是否损坏
- 确认是平台导出的原始文件（HTML格式的xls）

### Q2: 生成报告失败
- 查看页面"运行日志"展开栏中的错误信息
- 确认两个文件都已上传
- 确认时间范围正确

### Q3: 网页无法访问
- 检查端口是否被占用：`streamlit run streamlit_app.py --server.port 8502`
- Linux检查防火墙：`sudo ufw allow 8501/tcp`

### Q4: 下载的docx打不开
- 使用 Word 2007 或更高版本
- 检查下载是否完整

## 🔐 安全建议

1. **不要暴露到公网**：默认只监听 localhost
2. **文件大小限制**：Streamlit 默认单文件上限 200MB
3. **数据保护**：上传文件仅存内存/临时目录，生成后自动清理
