## 🚀 快速部署

### 方式一：Windows（双击即用）

1. 进入 `web_app/` 目录
2. 双击运行 `start.bat`（自动检查依赖并启动）
3. 浏览器自动打开 `http://localhost:8501`

### 方式二：Linux Docker Compose（推荐）

```bash
cd web_app
mkdir -p data
docker-compose up -d
# 访问 http://服务器IP:8501
```

### 方式三：Linux 直接运行

```bash
cd web_app
chmod +x deploy.sh
./deploy.sh                 # 创建venv、安装依赖、创建目录
nohup ./start.sh > logs/app.log 2>&1 &
./stop.sh                   # 停止
```

### 方式四：Systemd服务（生产环境）

```bash
cd web_app
python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt
sudo cp weekly-report.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now weekly-report
```

## 📊 程序说明

### 功能

自动生成"执法处建筑市场检查周报材料"docx 文件，包含两段正文：
- 正文一：本周全市建筑市场执法检查情况（检查量、问题、市级专项检查、前八区分析）
- 正文二：本周工程建设领域处罚情况（处罚量、每百工程处罚量排名）

### 输入数据（网页上传）

1. **检查原始数据导出**（.xls，HTML格式，如 检查数据0803.xls）
2. **处罚原始数据导出**（.xls，HTML格式，如 处罚数据0803.xls）

### 内置固定数据（无需上传）

1. **2025年建筑市场检查.xls** — 去年同期检查数/问题数
2. **2025年工程建设领域处罚.xls** — 去年同期处罚件数
3. **基本口径.xls** — 在施工程量、机构->行政区映射

## 📋 环境要求

### 网页应用
- Python 3.9+（建议 3.11）
- Streamlit、Pandas、OpenPyXL、xlrd、python-docx、lxml

### Docker
- Docker 20+、Docker Compose

## 💾 数据存储

| 数据 | 位置 | 说明 |
|------|------|------|
| 周报历史记录 | `data/周报历史记录.json` | 上周数值（环比一致性），可持久化 |
| 上传文件 | 内存/临时目录 | 生成后自动清理，不落盘 |
| 生成docx | 浏览器下载 | 服务端不保存 |

## ⚠️ 注意事项

1. **端口**：默认 8501（Streamlit），如需修改使用 `--server.port` 参数
2. **防火墙**：确保服务器防火墙放行 8501 端口
3. **时区**：Docker 方式已设置 `TZ=Asia/Shanghai`
4. **权限**：Linux 下确保程序有执行权限（`chmod +x *.sh`）
5. **上传大小**：Streamlit 默认单文件上限 200MB，原始导出文件通常 <20MB，无需调整

## 🔧 故障排除

### 网页应用无法启动

```bash
# 检查依赖
pip list | grep -E "streamlit|pandas"

# 重新安装
pip install streamlit --force-reinstall

# 使用不同端口
streamlit run streamlit_app.py --server.port 8502
```

### 生成报告失败

1. 确认上传文件为平台导出的 HTML 格式 .xls
2. 确认时间范围正确（文件上传后自动填充）
3. 查看页面"运行日志"展开栏中的详细错误
